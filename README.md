# PNPat and BCT-based SOXFE: Explainable EEG Dementia Classification

MATLAB implementation of the self-organized explainable feature engineering (SOXFE) model described in

> F. Balgetir, P.D. Barua, J. Shen, P. Narasimhan, S. Shivshankar, S. Dogan, I. Tasci, B. Tasci, M. Baygin, T. Tuncer, M. Kobayashi.
> *Self-Organized Explainable Dementia Detection from Electroencephalography Signals Using Directed Lobish and Previous-Next Pattern.*
> Journal of Clinical Medicine (under review, manuscript jcm-4632336).

The model combines the Bipartite Channel Transformer (BCT) and the Previous-Next Pattern (PNPat) for feature extraction,
cumulative weight-based iterative neighborhood component analysis (CWINCA) for feature selection, Directed Lobish (DLob)
for symbolic explainable outputs, the ensemble tkNN classifier with iterative majority voting (IMV), and combinational
majority voting (CMV) for information fusion.

## Validation protocols

The repository implements the three protocols reported in the revised manuscript:

| Protocol | Function | Participant-independent | Use in the manuscript |
|---|---|---|---|
| Segment-wise 10-fold CV | `run_segmentwise_cv.m` | No | Table 3 (secondary analysis) |
| Leave-one-subject-out (LOSO) | `run_grouped_protocol(..., 'loso')` | Yes | Tables 4-6 |
| Nested participant-grouped 10-fold CV | `run_grouped_protocol(..., 'group')` | Yes | Tables 4-6, Algorithm A1 |

**Important.** In the segment-wise protocol, segments of the same participant can be present in both the training and
the test folds, and all selection steps (normalization, CWINCA, tkNN/IMV, CMV) use the out-of-fold predictions of the
full data set. These accuracies (above 99% in the manuscript) are optimistic and do not measure generalization to
unseen participants. In the LOSO and nested protocols, every data-dependent step is fitted on the training participants
of each outer fold with participant-grouped inner folds, and the held-out participants are used only for evaluation.
The accuracies reported in the manuscript under these protocols are 51.19-63.81% (LOSO, segment level) and
49.00-62.50% (nested grouped CV); the model should therefore be regarded as a proof-of-concept and not as a clinical
diagnostic tool.

## Classification cases

| Case | Classes | Positive class (binary cases) |
|---|---|---|
| 1 | AD vs FD vs HC | - |
| 2 | Dementia (AD + FD) vs HC | Dementia |
| 3 | AD vs FD | AD |
| 4 | AD vs HC | AD |
| 5 | FD vs HC | FD |

AD: Alzheimer's disease, FD: frontotemporal dementia, HC: healthy controls.

## Requirements

- MATLAB R2020b or later (the manuscript results were obtained with MATLAB R2024a)
- Statistics and Machine Learning Toolbox (`fscnca`, `fitcknn`, `cvpartition`)
- No EEGLAB installation is needed; `read_eeglab_set.m` reads the `.set`/`.fdt` files directly.

## Data

The EEG data are publicly available from OpenNeuro, dataset **ds004504**
(<https://openneuro.org/datasets/ds004504>): resting-state, eyes-closed recordings of 36 AD, 23 FD and 29 healthy
participants, 19 channels (10-20 system), 500 Hz. Download the dataset (including `participants.tsv` and the
`derivatives/` folder with the preprocessed recordings) and set the path in `soxfe_config.m` or `main.m`:

```matlab
cfg.dataset_root = 'D:\data\ds004504';
```

The recordings are divided into non-overlapping 15-s segments (7500 samples). The manuscript reports 1943 AD,
1104 FD and 1614 HC segments (4661 in total); the loader prints the counts for verification.

## Usage

```matlab
% quick check on synthetic data (no EEG data required)
test_soxfe_smoke

% full analysis
main
```

`main.m` extracts and caches the features (`results/features.mat`), runs the selected protocols for Cases 1-5, and
writes the results with `export_results.m`. LOSO retrains the complete model once per participant (88 times for
Case 1); to run only the faster protocols, set `cfg.protocols = {'segment', 'nested'};`.

## Outputs (`results/`)

| File | Content |
|---|---|
| `summary_metrics.csv` | accuracy with Wilson 95% CI, geometric mean, balanced accuracy, macro-F1 (segment and participant level) |
| `classwise_metrics.csv` | sensitivity, specificity, precision, NPV, F1 per class |
| `confusion_matrices.csv` | confusion matrices |
| `per_participant_<protocol>_case<k>.csv` | per-participant number of segments, accuracy and majority-vote prediction |
| `folds_<protocol>_case<k>.csv` | participant, fold and prediction of every segment (fold assignments) |
| `selected_features.csv` | number of CWINCA-selected features and reduction ratio |
| `dlob_sentences.txt`, `dlob_entropy.csv`, `dlob_transition_case<k>.csv` | DLob sentences, entropies and average transition tables |
| `results.mat` | complete result structures and trained segment-wise models |

## Reproducibility

All fold assignments are generated by `make_folds.m` with the fixed random seed `cfg.seed = 1` (inner folds of outer
fold *k* use seed `1 + k`). Segment-wise folds are stratified by class; grouped folds shuffle participants within each
class and assign them to folds in turn, so that every participant belongs to exactly one fold. The fold assignment of
every segment is written to `folds_<protocol>_case<k>.csv`.

## Main settings (`soxfe_config.m`)

| Component | Setting |
|---|---|
| CWINCA | NCA (`fscnca`, L-BFGS); start/stop thresholds 0.85 / 0.9999 of the cumulative weight; loss: kNN (k = 1, city block) |
| tkNN | distances {city block, Euclidean, cosine} x weights {squared inverse, equal} x k = 1-5 (30 settings); IMV over the top 3-30 settings; best of 58 outcomes |
| CMV | combinations {1,2,3}, {1,3,4}, {2,3,4}, {1,2,3,4} of the four outcomes; best of 8 outcomes |
| DLob look-up table | FL FR FL FL Fz FR FR TL CL Cz CR TR TL PL Pz PR TR OL OR (Fp1 ... O2) |

## Reported run times

For Case 1 (4661 segments) in MATLAB R2024a on a laptop with 32 GB RAM, the manuscript reports 0.012 s per segment for
feature extraction, 1500 s for CWINCA (four feature vectors), 60 s for tkNN with IMV, 1650 s of total training time
(segment-wise protocol), and 0.020 s per segment for classification.

## Notes on interpretation

DLob sentences and transition tables describe the channel transitions retained by the feature selector. They are
feature-driven visualizations and are not measures of functional or effective connectivity; DLob entropy describes the
diversity of the selected feature symbols, not cortical complexity.
